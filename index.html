Adapting a Text-to-Audio Model for
Room Impulse Response Generation

Kirak Kim  ·  Sungyoung Kim
Graduate School of Culture Technology, KAIST, South Korea
📄 Paper 💻 Code

Abstract

Room Impulse Responses (RIRs) enable realistic acoustic simulation, with applications ranging from multimedia production to speech data augmentation. However, acquiring high-quality real-world RIRs is labor-intensive, and data scarcity remains a challenge for data-driven approaches. We propose adapting a pre-trained text-to-audio model for RIR generation — demonstrating for the first time that large-scale generative audio priors can be effectively leveraged for this task. Using a VLM-driven labeling pipeline and an in-context learning strategy, our model generates plausible, full-bandwidth RIRs from free-form text descriptions using only a small set of real-world RIR data.
